# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of TallyPitch match data and user authentication seriously.

If you discover a security vulnerability:
1. Please do **NOT** disclose the vulnerability publicly in an open GitHub issue.
2. Email full vulnerability details, reproduction steps, and potential impact to **manvenpratapsingh@gmail.com**.
3. We will acknowledge receipt within 48 hours and work on a fix promptly.
